🚗 Car Rental Management System

A backend-based Car Rental Management System built using Python and MySQL.
This project implements full CRUD (Create, Read, Update, Delete) operations while maintaining proper database relationships and rental logic.


📌 Project Overview

This system allows management of:

👤 Customers

🚘 Cars

📄 Rentals

💾 Database records with relational integrity

The application connects Python with MySQL to handle real-time data storage and updates, simulating how a real-world rental system works.


⚙️ Features

✅ Add new customers

✅ Add & manage cars

✅ Issue rentals

✅ Update rental status

✅ Delete records

✅ Maintain relational database constraints

✅ Enforce car availability logic


🛠️ Technologies Used

Python – Backend logic

MySQL – Database management

MySQL Connector (Python) – Database connectivity

SQL (DDL & DML) – Table creation & data manipulation


🗄️ Database Design

The system uses relational tables such as:

customers

cars

rentals

Relationships are maintained using:

Primary Keys

Foreign Keys

Constraints

This ensures data integrity and prevents invalid entries.
